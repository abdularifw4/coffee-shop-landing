# Brewed Awakening ☕

> Specialty Coffee Landing Page — Dark premium theme

A modern, responsive landing page for a specialty coffee shop in Jakarta. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies.

## Features

- 🎨 Dark premium theme with warm gold accents
- 📱 Fully responsive (mobile, tablet, desktop)
- 🍔 Mobile hamburger menu
- 🎭 Scroll animations (Intersection Observer)
- 📝 Reserve a table form with validation feedback
- 🎯 Smooth scrolling navigation
- 📊 Stats section
- 🍽️ Menu showcase with pricing
- 💬 Customer testimonials
- 📍 Contact section with map placeholder

## Sections

1. **Navbar** — Fixed, blur-on-scroll
2. **Hero** — Full-screen with CTA
3. **Stats** — Quick numbers
4. **Menu** — 4 best-seller cards
5. **About** — Brand story + features
6. **Gallery** — Masonry-style grid
7. **Testimonials** — 3 review cards
8. **Contact** — Info + reservation form
9. **Footer** — Links + socials

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Playfair Display + Inter)
